# SYNC — Internship Opportunity Tracker

Static GitHub Pages dashboard built with HTML, CSS, Vanilla JavaScript and JSON.

## Run
Open `index.html` through a static server (recommended) or deploy the folder to GitHub Pages.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders.
3. Repository → Settings → Pages.
4. Deploy from `main` branch and `/root`.
5. Open the generated Pages URL.

Bookmarks and personal application statuses use browser LocalStorage.
